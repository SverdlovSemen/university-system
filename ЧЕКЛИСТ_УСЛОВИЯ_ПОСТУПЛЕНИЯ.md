## Заметки разработчика

- Все поля формы (кроме года) необязательные для гибкости
- Год является уникальным ключом для условий поступления в рамках одной программы
- Валидация реализована на двух уровнях: фронтенд и бэкенд
- API следует REST стандартам
- Все эндпоинты защищены Spring Security
- Используется единый стиль кода с остальным проектом
